# Submission description

Teachback Lab is a learning-by-teaching adventure for elementary learners. Children explore Discovery Island, explain science and math ideas to Pip the robot, revise their thinking, and apply each concept in a new challenge. Six missions combine short lessons, optional read-aloud, discovery badges, and saved effort stars.

Built with React, TypeScript, validated server routes, and Cloudflare D1, the app includes a lesson-grounded AI coach integration through Vercel AI Gateway and a clearly labeled practice fallback. The next steps are broader model evaluation, educator review, and privacy and classroom-readiness work.

**Current disclosure:** Vercel's first live request was blocked pending account/card verification; successful live AI feedback has not yet been demonstrated. The LGPL dependency has been removed, but additional MPL-licensed tooling remains flagged in the dependency audit. Do not represent the project as fully cleared for submission until those findings are resolved.

**AI and third-party disclosure:** Codex assisted with implementation, lesson drafts, tests, and documentation under the owner's direction. Pip and Discovery Island artwork were generated with OpenAI image generation. The project extends a Sites/Vinext starter and uses the components, licenses, and services listed in `THIRD_PARTY_NOTICES.md` and `docs/DEPENDENCY_LICENSES.csv`. No real learner dataset is used for the demo.
